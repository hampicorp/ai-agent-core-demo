# AI Agent Core Demo

[![CI](https://github.com/hampicorp/ai-agent-core-demo/actions/workflows/ci.yml/badge.svg)](https://github.com/hampicorp/ai-agent-core-demo/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

Небольшое тестируемое ядро для ИИ-агентов, использующих инструменты. Репозиторий показывает архитектурный подход Hampi Corp без клиентского кода и внешнего AI API.

## Что здесь важно

- AI/LLM отделён от оркестрации интерфейсом `Planner`;
- инструменты имеют явную валидацию входных данных;
- используется allow-list доступных инструментов;
- есть ограничение числа шагов и таймаут выполнения;
- каждое действие попадает в неизменяемый журнал событий;
- критичные политики покрыты автоматическими тестами.

## Быстрый запуск

```bash
npm ci
npm run check
npm run demo
```

Требуется Node.js 20 или новее.

## Архитектура

```text
Goal -> Planner -> Policy checks -> Tool -> Observation
             ^                         |
             +-------------------------+
```

`Agent` отвечает за полный жизненный цикл выполнения. Конкретная модель подключается только через `Planner`, а бизнес-интеграции — через маленькие объекты `Tool`. Благодаря этому код можно проверять без сети и без случайного поведения модели.

## Что нужно добавить для production

- постоянное хранилище журнала;
- аутентификацию и разграничение прав;
- лимиты стоимости и частоты вызовов;
- защиту персональных данных;
- подтверждение человеком перед необратимыми действиями;
- наблюдаемость, трассировку и метрики качества.

Это демонстрационный проект, а не готовая платформа и не копия клиентской системы.
